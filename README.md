# Attendance Buddy — GitHub Pages PWA

This folder contains the installable web-app version of Attendance Buddy.

## Publish it free with GitHub Pages

1. Sign in to GitHub and create a **Public** repository named `attendance-buddy`.
2. Open the repository, choose **Add file → Upload files**, and upload every file in this folder (upload the files themselves, not the enclosing folder).
3. Commit the upload to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**; select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to publish. The site URL will look like `https://YOUR-USERNAME.github.io/attendance-buddy/`.
7. Open that URL in Chrome on your Android phone. Open the Chrome menu (⋮) and choose **Install app** or **Add to Home screen**.

## Important
- Keep `index.html`, `manifest.webmanifest`, `sw.js`, and the PNG icons together in the repository root.
- Attendance data is stored in this browser on this device. It is not automatically synced to GitHub or other devices. Use the app's export/backup option if available before clearing browser data or changing phones.
- GitHub Pages is public hosting: do not put private information or secrets in repository files.
